# Module map

The table describes runtime responsibilities and communication channels at a conceptual level.

| Module                         | Responsibility                                                                       | Communicates with                                                                      | How                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Application bootstrap          | Starts services, wires room events, and coordinates shutdown and recovery.           | Session, room, command, audio, admin, and lifecycle modules.                           | Direct calls; internal events; HTTP health check; process IPC. |
| Session module                 | Obtains and renews the runtime session using a headless browser for login.           | Application bootstrap and browser runtime.                                             | Direct calls; internal events.                                 |
| Real-time connection module    | Manages the platform's real-time connection.                                         | External platform; room connector; application bootstrap.                              | WebSocket; internal events.                                    |
| Platform REST client           | Provides supporting platform operations.                                             | External platform; commands and room connector.                                        | HTTP REST; direct calls.                                       |
| Room connector                 | Manages room participation and translates incoming activity into application events. | Real-time connection, commands, player, and audio service.                             | WebSocket-backed events; internal events; direct calls.        |
| Command dispatcher             | Routes music and room commands and coordinates playback actions.                     | Room connector, player, search, radio, settings, and audio modules.                    | Direct calls; internal events.                                 |
| Audio source search            | Finds candidate tracks and related information for playback.                         | Search service and command dispatcher.                                                 | HTTP through a library; direct calls.                          |
| Room radio coordinator         | Coordinates room radio playback state and stream selection.                          | Platform radio controls and audio service.                                             | HTTP REST; direct calls.                                       |
| Conversational AI orchestrator | Coordinates optional conversational behavior and its supporting modules.             | Room events, conversation, guardrails, provider, memory, relation, and player modules. | Internal events; direct calls; HTTP through providers.         |
| Conversation guardrails        | Applies runtime guardrails to conversational processing.                             | AI orchestration and conversation handling.                                            | Direct calls.                                                  |
| Conversation runtime state     | Tracks and cancels per-room conversational work.                                     | AI orchestration and conversation state.                                               | Direct calls.                                                  |
| Conversation processor         | Manages conversational state and response processing.                                | AI orchestration and runtime coordination.                                             | Direct calls.                                                  |
| AI provider cascade            | Tries configured AI providers and returns a usable response when available.          | External AI services and AI orchestration.                                             | HTTP; direct calls.                                            |
| AI memory store                | Reads and updates room-scoped conversational memories.                               | SQLite and AI orchestration.                                                           | SQLite; direct calls.                                          |
| Personality settings           | Reads and updates configurable conversational personalities.                         | SQLite and AI orchestration.                                                           | SQLite; direct calls.                                          |
| User relation store            | Reads and updates room-scoped user relationship state.                               | SQLite and AI orchestration.                                                           | SQLite; direct calls.                                          |
| Room settings                  | Reads and updates per-room language and AI settings.                                 | SQLite, commands, and AI modules.                                                      | SQLite; direct calls.                                          |
| Room restriction store         | Reads and updates room-scoped participation restrictions.                            | SQLite and command handling.                                                           | SQLite; direct calls.                                          |
| Localization catalog           | Supplies localized user-facing text.                                                 | Commands, room settings, and AI modules.                                               | Direct calls.                                                  |
| Admin panel server             | Serves the administration interface and its control operations.                      | Local browser, SQLite, and local status/control services.                              | HTTP; SQLite; direct calls.                                    |
| Admin command-line tool        | Provides command-line client administration.                                         | SQLite.                                                                                | Direct calls; SQLite.                                          |
| Bot status and heartbeat       | Publishes process status and heartbeat information.                                  | SQLite and admin panel.                                                                | SQLite; direct calls.                                          |
| Structured logger              | Records structured operational events.                                               | Runtime modules.                                                                       | Direct calls.                                                  |
| Audio streaming service        | Runs the HTTP audio service and manages extraction, conversion, and stream state.    | Main process, local media tools, and HTTP clients.                                     | Process IPC; HTTP; child processes.                            |
| Room player state              | Maintains in-memory queues and playback state per room.                              | Commands, room connector, and audio service.                                           | Direct calls.                                                  |
| Room lifecycle manager         | Reconciles desired client state in SQLite with active room participation.            | SQLite, application bootstrap, and room connector.                                     | SQLite; direct calls; internal events.                         |
| Runtime path resolver          | Resolves platform-specific executable paths.                                         | Application modules and local environment.                                             | Direct calls; operating-system process lookup.                 |
| Stream metrics monitor         | Collects and prints local audio-service metrics.                                     | Audio service.                                                                         | HTTP; direct calls.                                            |
| SQLite database access         | Opens the shared SQLite database and ensures required structures exist.              | Modules that persist client, room, or AI state.                                        | SQLite; direct calls.                                          |
| Runtime package configuration  | Defines the Node.js runtime, dependencies, and process entry points.                 | Node.js and application launchers.                                                     | Direct process invocation.                                     |
